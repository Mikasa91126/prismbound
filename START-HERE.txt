《棱镜奇旅 · PRISMBOUND》v1.0.4
原创 2D 横版像素炼金平台冒险 —— 零安装、零联网、零外部素材

【怎么开始】
1. 把压缩包完整解压到任意文件夹（不要在压缩包里直接双击）。
2. 双击 index.html，用 Chrome 或 Edge 打开。
3. 按 Enter 或点击画面唤醒音频，音乐响起后即可游玩。

【操作速查】
← → / A D      移动
Space / Z      跳跃（按住跳得更高；空中再按一次 = 二段旋跳）
Shift / X      八向冲刺（空中可向八个方向）
↓（奔跑中）    滑铲，可钻过 1 格高的窄洞；滑铲中起跳 = Wave-Slide 跃冲
空中 Shift+↓   陨石砸地，可砸碎裂缝地板
1 2 3 4        切换四种棱镜形态（烈焰 / 霜晶 / 星蚀 / 星隙）
J / E          形态技能（↓ + J 为次级技能）
F              回响分身：录制 4 秒行动并释放分身
按住 L / V     子弹时间：世界与音乐一起减速
Tab            打开 16 种炼金连携图鉴
Esc / P        暂停        M  静音

【小提示】
· 卡关时试试换形态：冻水成桥、点燃藤蔓、翻转重力、掷出星棱瞬移。
· 进度自动保存在浏览器里，关掉再开可以继续旅程。
· 完整说明见 README.md；推荐桌面端最新版 Chrome / Edge。
· 全部像素画、音乐与音效均由代码实时生成，没有任何外部素材文件。
